# 👶 Echo Baby

### Умная аудио-няня и звуковой регистратор в одном веб-приложении

> Слушает микрофон. Записывает только тогда, когда есть что слушать.
> Благодаря 2-секундному предбуферу — вы никогда не упустите начало.

**🔗 Демо: [echo-baby-roan.vercel.app](https://echo-baby-roan.vercel.app/)**

---

## ✨ Что это вообще такое?

Одностраничное веб-приложение, которое постоянно слушает микрофон и автоматически сохраняет аудио в формате WAV (PCM 16 бит), как только уровень звука превышает порог, заданный вами.

**Главная фишка — кольцевой предбуфер на 2 секунды.**  
Запись начинается *за 2 секунды до* срабатывания триггера. Плач, крик, первая нота, первое слово — всё будет записано с самого начала, а не с середины.

---

## 🌟 Зачем это в реальной жизни?

| Сценарий | Что даёт |
|---|---|
| 👶 **Аудио-няня** | Оставьте планшет в детской — утром прослушаете всё: кряхтение, агуканье, плач, первые слова |
| 🛡️ **Домашний регистратор** | Ушли из дома — вкладка ловит резкие звуки: лай, звонок, разбитое стекло |
| 🎙️ **Умный диктофон** | Записывает только живую речь, а не часы тишины и гигабайты пустоты |
| 🎸 **Репетиции и вокал** | Каждый дубль сохраняется автоматически, атака первой ноты не срезается |

## 🎨 Что внутри (и почему это не скучно)

**6 живых визуализаторов звука** — реагируют на голос в реальном времени через Web Audio API (FFT Spectrum):

- **Classic Bars** — сочные градиентные столбики от центра
- **Mirror Wave** — профессиональная зеркальная звуковая волна
- **Circular Siri** — радиальные неоновые лучи вокруг кнопки старта
- **Liquid Blob** — «живое» органическое пятно, меняющее форму от звука
- **Particles Field** — 120 частиц-светлячков с физикой взрыва от басов
- **Retro Neon Grid** — неоновая сетка в стиле синтвейв

**6 палитр в один клик** — Violet, Rose, Sky, Emerald, Amber, Zinc.  
Плюс глубокая тёмная и светлая темы.

## 🚀 Возможности

- ⚡ **Полный офлайн-режим** — всё хранится в IndexedDB прямо в браузере. Перезагрузил страницу — записи на месте
- 🌊 **6 canvas-визуализаторов** — 60 FPS без нагрузки на процессор (RequestAnimationFrame)
- 🎨 **Живой переключатель палитр** — Untitled UI концепт, 6 цветов + 2 темы
- 🔒 **100% приватность** — ни один байт аудио не уходит на сервер. Всё локально
- ⭐ **Избранное под защитой** — автоочистка никогда не удалит то, что вы отметили
- 🎚️ **Настраиваемый лимит записей** — от 10 до 500 дорожек, старые удаляются автоматически
- 📱 **Работает на iOS Safari** — свой PCM-WAV кодировщик, без сторонних библиотек

---

## 🛠 Технический стек

- **Фреймворк:** Next.js 15+ (App Router, Client-Side Rendering)
- **Стили:** Tailwind CSS v4 (Untitled UI концепт)
- **Анимации:** Tailwind animate + RequestAnimationFrame для Canvas (60 FPS)
- **Аудио-движок:** Web Audio API — `AudioContext`, `AnalyserNode`, `AudioWorkletNode`
- **Кодирование:** кастомный PCM-WAV кодировщик (воспроизведение на iOS Safari без библиотек)
- **Хранилище:** браузерная СУБД IndexedDB (без бэкенда)
